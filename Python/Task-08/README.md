# Task 8 – Introduction to Pandas

## Objective
The objective of this task is to learn the basics of Pandas, create Series and DataFrames, read different file formats, and inspect datasets.

## Topics Covered

### Why Pandas?
Pandas is used to store, organize, clean, and analyze data efficiently.

### Series
A Series is a one-dimensional data structure.

Example:
```python
import pandas as pd
s = pd.Series([10,20,30])
```

### DataFrame
A DataFrame is a two-dimensional table with rows and columns.

Example:
```python
df = pd.DataFrame(data)
```

### Reading Files
Pandas can read different file formats.

- `read_csv()`
- `read_excel()`
- `read_json()`

### Data Inspection
Useful functions:
- `head()`
- `tail()`
- `info()`
- `describe()`

## Skills Learned
- Importing Pandas
- Creating Series and DataFrames
- Reading CSV, Excel, and JSON files
- Inspecting datasets
- Understanding dataset structure
