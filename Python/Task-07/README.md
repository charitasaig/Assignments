# Task 7 – NumPy

## Objective
The objective of this task is to learn the basics of NumPy and perform numerical operations efficiently using arrays.

## Topics Covered

### NumPy Arrays
NumPy provides the `ndarray` object for storing numerical data.

Example:
```python
import numpy as np
arr = np.array([1,2,3,4,5])
```

### Array Operations
NumPy supports fast mathematical operations such as:
- Addition
- Subtraction
- Multiplication
- Division

### Array Indexing & Slicing
Access specific elements or a range of elements using indexes.

Example:
```python
arr[0]
arr[1:4]
```

### Reshaping Arrays
Change the shape of an array using `reshape()`.

Example:
```python
arr.reshape(2,3)
```

### Statistical Functions
Common functions:
- `sum()`
- `mean()`
- `max()`
- `min()`
- `std()`

- Mathematical operations
