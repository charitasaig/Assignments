# Task 06 - Python with MySQL

## Objective

Learn how to connect Python with a MySQL database and perform basic database operations using SQL queries.

## Topics Covered

- MySQL Database Connectivity
- mysql.connector Module
- Database Connection
- Creating Cursor Objects
- Executing SQL Queries
- Creating Tables
- Inserting Records
- Updating Records
- Deleting Records
- Retrieving Data (SELECT)
- Fetching Records
- Committing Transactions
- Closing Database Connections


## Technologies Used

- Python
- MySQL
- MySQL Workbench
- mysql.connector

## Learning Outcomes

- Connected Python applications to a MySQL database
- Performed CRUD (Create, Read, Update, Delete) operations
- Executed SQL queries from Python
- Retrieved and displayed database records
- Managed database transactions and connections effectively
